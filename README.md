# CRUD PHP

Simple PHP application to register, list and delete users in a MySQL database.

## Features

- Add users through a form
- List registered users
- Delete users

Database access uses **PDO** with a `usuarios` table.

## Stack

PHP, PDO, MySQL, HTML and CSS.

## Running locally

1. Create a MySQL database with a `usuarios` table.
2. Adjust the connection settings at the top of `index.php`.
3. Start the PHP built-in server:

```bash
php -S localhost:8000
```

4. Open http://localhost:8000.
